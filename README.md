## What it does

`main.ts` (Node 22, standard library only) writes one line — at most 200 characters, about a small good thing that happened today — to `/output/entry.txt`, followed by a single trailing newline.

The line it writes (120 characters):

> The bus driver held the door for a sprinting schoolgirl, then grinned at the whole bus like we'd all just won something.

## Run

```sh
node main.ts
cat /output/entry.txt
```
